# Tkinter GUI Viewer - XED Editor Extension

## Installation Guide

### Quick Install (Recommended)

1. **Open XED Editor** on your Android device
2. **Go to Settings** → **Feature Toggles**
3. **Enable Extensions**
4. **Go back** and open **Extensions section**
5. **Tap "Install from Storage"** button (FAB)
6. **Select this ZIP file** to install

### What's Inside

- **manifest.json** - Extension metadata and configuration
- **plugin.js** - Extension entry point for XED Editor
- **src/** - Kotlin source code for the VNC viewer
- **README.md** - Full documentation

### Features

✨ View Python Tkinter GUIs through VNC directly in XED Editor
🔧 Automatic VNC server setup
🌉 WebSocket bridge for secure connection
📱 Works on phones, tablets, and desktops
⚡ Fast startup (3-5 seconds)

### Requirements

- **XED Editor v3.0+** installed on your Android device
- **Ubuntu/Alpine terminal** available in XED
- **Python 3** (for running Tkinter applications)

### Troubleshooting

If installation fails:
1. Make sure XED Editor is up to date
2. Check that Extensions are enabled in Settings
3. Try clearing XED Editor cache (Settings → App Info → Storage → Clear Cache)
4. Restart XED Editor and try again
